# stt-transcribe

Tools for transcribing and translating subtitles.

## Setup

This project depends on [subtitle-translator](https://github.com/your-org/subtitle-translator). 
Create a symlink or clone it alongside this repo:

```bash
ln -s /path/to/subtitle-translator subtitle-translator
```

Or if you want to clone it in the parent directory:

```bash
git clone <subtitle-translator-repo> ../subtitle-translator
```

The `subtitle-translator/` directory is gitignored and not tracked by this repo.
